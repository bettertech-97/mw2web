# web/assets

The lobby (`web/index.html`) and the docs page (`web/docs/`) load these files. They
are not in the repository: the fonts and texture belong to their authors, and the map
pictures are game art. Put them here yourself.

| File | Where it comes from |
|---|---|
| `fonts/Chivo Mono/chivo-mono-400-normal.woff2`, `chivo-mono-700-normal.woff2` | Chivo Mono, [Fontsource](https://fontsource.org/fonts/chivo-mono), SIL Open Font License 1.1 |
| `fonts/League Gothic/league-gothic-400-normal.woff2` | League Gothic, [Fontsource](https://fontsource.org/fonts/league-gothic), SIL Open Font License 1.1 |
| `textures/str_metalgen5.png` | [Torment Retro Textures](https://strideh.itch.io/torment) by Strideh: free for open-source projects with attribution, not for resale as assets. Any dark 256 px metal tile works. |
| `maps/<map>.jpg` | A 960x540 picture per map, named by its zone (`mp_rust.jpg`). For the MW2 maps, the loadscreens (`loadscreen_<map>`) in your own install's `main/iw_01.iwd`. |

Michroma, the heading font, loads from Google Fonts.
